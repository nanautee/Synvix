Release Notes

Synvix v1.2.0

August 2025

New Features
🧠

Question Classifier New

Synvix now understands the difference between an interviewer asking a question and just talking. When the interviewer explains something or gives instructions, the AI stays quiet — no more irrelevant answers flooding in during casual conversation.

🌐

Custom Base URLs New

Use any compatible API endpoint — OpenRouter, self-hosted models, or enterprise proxies. Set custom base URLs for both LLM and STT providers independently.

🗣️

26 Languages New

Interview support expanded to 26 languages. Both speech-to-text transcription and AI answers now work in your native language — from English to Vietnamese.

Improvements
⚡

Auto-detect Provider Improved

Enter a Groq API key — Synvix automatically switches to Groq. No more manually selecting the provider. The model resets correctly too.

🔄

Updated Model Lineup Improved

Groq models updated to current API: GPT-OSS 120B, GPT-OSS 20B, and Qwen 3.6 27B replace the deprecated Llama lineup.

🛡️

Server-side Validation Fix

Added model validation on both client and server. The model always matches the selected provider — no more 404 errors from mismatched configs.
